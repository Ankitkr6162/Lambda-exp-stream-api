**Lambda is a anonymous function has no name, no modifier and no return type.

Benefits of Lambda expression :-
Reduces the lines of code.
Sequential and parallel execution support by passing behavior as an argument in methods.
To call APIs very effectively.
To write more readable. maintainable and concise code.

Rules:-
If body of lambda expression contains only one statement then curly braces are optional.
For lambda expression, Java compiler also infer the type of variable passed in arguments, hence type os optional.

**Functional Interface 
If the interface contains only one abstract method then it is called Functional interface.
eg- Runnable, Callable, Comparable etc.
Functional reference can hold lambda expression.
To call lambda we require functional interface.
